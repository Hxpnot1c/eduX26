Call this when the student asks for a plan for an upcoming test or assignment, or how to spread their revision.

- assessment_id: the id from their profile; with none, the soonest upcoming one.
- sessions_per_week: how many sessions a week they want (1 to 7); with none, the default of 3.

Returns a day-by-day plan from today to the due date: the topics each day, weakest first, ending with mixed practice. For a written assignment it returns dated stages (knowledge, application, analysis, evaluation) that say what to do, never what to write. Read the plan out in plain words, say the dates can move, and never write any of their assessed answer for them.
