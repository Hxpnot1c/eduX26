# Overnight research

Research to make eduX a stronger entry for Cambridge EduX 2026, Challenge 1 ("Beneath the Surface: Defining and Assessing AI Literacy"). It builds on the personalisation review in [`../personalisation.md`](../personalisation.md) and does not repeat it.

Read [`MORNING-BRIEF.md`](MORNING-BRIEF.md) first.

## Files
| file | what it holds |
|---|---|
| `MORNING-BRIEF.md` | One page: what to do on Wednesday, pitch points, risks, what changed |
| `findings.csv` | Every verified finding (✓ or ~). ✗ findings are dropped |
| `judge-panel.md` | Red-team objections per wave and their status |
| `pitch-notes.md` | Claims we can make, with sources, and claims to avoid |
| `demo-plan.md` | Video storyboard, live-demo script and fallbacks |
| `business-plan.md` | Market, buyers, pricing, competitors, risks, evaluation |
| `NN-*.md` | One report per research area |
| `sims/` | Simulation scripts and results (synthetic students, example pack only) |

## Method
Each wave: 6–8 scouts research one question each; at least two blind verifiers check every claim against its source (they see claims and sources only); a judging panel attacks the product; an editor rewrites the reports and brief. Marks: ✓ confirmed, ~ broadly supported with a stated problem, ✗ dropped.
